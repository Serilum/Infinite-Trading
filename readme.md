<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Infinite Trading is a minimalistic mod which prevents villager trades from locking up, making them always available and allowing infinite trading. I'm not sure where they get the items from, but as long as emeralds are involved they'll find a way. The wandering trader is supported and enabled by default. This can be turned off in the config.</span></p>
